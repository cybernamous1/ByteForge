About ByteForge

Build freely. Develop locally. ByteForge is a developer-controlled workspace that runs in your browser: a Monaco editor, a project file tree, a terminal, a Node.js runtime where supported, sandboxed JavaScript and Python runners, a SQLite database studio, static and runtime previews, and portable ZIP import/export.

Principles

  • Browser-first execution — code runs on your device.
  • Local project storage — files live in your browser, and you can export them at any time.
  • No mandatory accounts, paid APIs, external AI services or cloud databases.
  • Transparent limitations — the documentation states what works, what is experimental and what is not implemented.
  • Developer ownership — your code and data are yours.

Built with

Monaco Editor, xterm.js, sql.js, JSZip, WebContainers (optional), Pyodide (optional, on demand) and Vite. See Documentation for licenses.

Operator contact

The source distribution does not include operator details. If you deploy ByteForge publicly, replace this paragraph in public/about.html with your name or organization, a contact address and the governing law that applies to your deployment.
