Privacy Policy

This policy describes what the ByteForge software does. The operator of the website where you found it may add their own practices; see the About page.

Summary

  • No accounts, no sign-in, no analytics, no advertising, no tracking pixels and no cookies set by the application.
  • Your projects and databases are processed and stored on your device.
  • Network requests to third parties happen only when you start optional features, listed below.

Data stored on your device

DataWherePurpose
Project files, folders, open tabs, SQL editor textIndexedDB (byteforge)Keeping your workspace between visits
SQLite database fileIndexedDBKeeping Database Studio data
Preferences (theme, font size, …)localStorage (byteforge.settings)Remembering your settings

This data is not encrypted and is readable by anyone with access to your browser profile, by browser extensions with site access, and by any script running on this origin. You can remove everything with Settings → Delete all local data, or by clearing site data in your browser.

Network requests

WhenWho receives a requestWhat
Loading ByteForgeThe hosting provider of this deployment (for example Cloudflare)Standard web request data such as IP address, user agent and requested URL, handled under that provider's and the operator's policies. ByteForge's code, editor, SQLite engine and fonts are served from the same origin; no third-party CDN is used for them.
You start the Node.js runtime and confirm the promptStackBlitz (WebContainers)The browser loads WebContainer assets. Your project files are mounted inside the browser and are not uploaded by ByteForge. StackBlitz's own privacy policy applies to its servers.
You run npm install in the runtimeThe npm registryPackage names and versions you request.
You run Python and confirm the promptcdn.jsdelivr.netDownload of Pyodide files.
Your own code makes requests (preview, runtime, fetch)Whatever hosts your code contactsDetermined entirely by your code.

What ByteForge does not do

It does not send your files, database, secret-detection findings or usage statistics anywhere. Secret detection runs entirely in your browser.

Children

ByteForge is a developer tool and is not directed at children.

Changes

This page is updated together with the software when behavior changes.
